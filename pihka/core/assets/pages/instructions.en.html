How to use this site

The home page lists the tables and curated views in this dataset. Open one to start exploring.

Browsing

  • Views — switch between a table, cards, or (where the data has coordinates) a map using the buttons above the list.
  • Sorting — click a column header in the table view to sort by it; click again to reverse.
  • Detail pages — click a row's identifier to open its full record, including related items from other tables.

Filtering and search

  • Filters — the sidebar offers a filter for each meaningful column: ranges for numbers, checklists for categories, and a map for locations.
  • Full-text search — the search box in the sidebar searches within a table; the search box in the header searches across every table at once.

Sharing and language

  • Shareable links — filters, sorting, the page you are on, and the active view all live in the address bar, so copying the URL reproduces exactly what you see.
  • Language — if the dataset offers more than one language, use the switcher in the header; your choice is remembered.
  • Theme — the light/dark toggle follows your system by default.
