Over deze site

Deze website is gebouwd met Pihka, een platform zonder backend voor het publiceren van onderzoeksdatasets. De volledige dataset zit in één SQLite-bestand dat één keer wordt gedownload en rechtstreeks in je browser wordt bevraagd met WebAssembly — er is geen databaseserver, geen API, en er wordt niets teruggestuurd naar een host terwijl je browst.

Omdat alles uit statische bestanden bestaat, kan de site overal gehost worden — een universitaire webruimte, GitHub Pages, een institutionele repository of een archief — en blijft ze werken zolang die bestanden bereikbaar zijn. Die duurzaamheid op lange termijn is het opzet: gepubliceerde onderzoeksdata moet het project overleven dat ze heeft voortgebracht.

Deze pagina aanpassen

Dit is de standaard Over-pagina van Pihka. Een dataset kan ze vervangen — en eigen menu-items toevoegen — via een app/menu.json die naar eigen HTML-pagina's verwijst. Zie de projectdocumentatie voor de footer- en menuconfiguratie.
